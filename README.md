# 📊 Cadastro e Análise de Dados em Python

Programa desenvolvido em Python para registrar informações de pessoas e realizar análises a partir dos dados cadastrados.

## Funcionalidades

- Cadastro de pessoas
- Armazenamento de informações em listas
- Identificação de pessoas de acordo com critérios definidos
- Análise dos dados registrados
- Apresentação dos resultados no terminal

## Tecnologias

- Python 3

## Conceitos praticados

- Listas
- Listas compostas
- Estruturas condicionais
- Laços de repetição
- Organização e análise de dados

## Como executar

```bash
python analise_dados.py
```

## Objetivo

Praticar estruturas de dados compostas e desenvolver operações de cadastro, consulta e análise de informações.
